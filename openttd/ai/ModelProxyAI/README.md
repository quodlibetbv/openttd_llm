# ModelProxyAI Foundation Package

`ModelProxyAI` establishes the benchmark company boundary and is otherwise inert. It emits a fixed readiness heartbeat to the dedicated-server console and persists an empty state table so its `Load` callback can emit the marker while the fixed starting save remains paused. It contains no construction, vehicle, finance, or order API calls; this Phase 02 heartbeat is its only defined behavior beyond ownership. Future heartbeat semantics must be changed through a versioned contract.
